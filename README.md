# Automated Linux Server Provisioning & Health-Check Toolkit

A Python-based Linux administration and automation toolkit that simplifies common server administration tasks such as system monitoring, user management, service management, server provisioning, logging, and health-report generation.

The project combines **Python and Bash** to provide a simple menu-driven interface for Linux server operations.

---

## 📌 Project Overview

Managing Linux servers often requires running many commands manually.

This toolkit brings common administrative operations into a single interface.

Instead of manually running commands such as:

systemctl status nginx
free -h
df -h
top
useradd
